Research Projects

AutoFiC

LLM-based Automated Security Patch Pipeline

Developed an end-to-end pipeline combining static application security testing (SAST), LLM-based patch generation, automated patch application, and pull request creation for Python open-source projects. The pipeline completed successfully on 86 of 91 projects (94.5%) and eliminated 397 of 441 static-analysis warnings (90.0%). Warning removal does not itself establish patch correctness.

ICST 2026 Research

LLM-based Automated Patch Correctness Assessment

Analyzed recurring failure patterns in LLM-based patch validation and developed six prompting strategies for identifying incorrect patches. Improved incorrect-patch detection performance by up to 19.9 percentage points relative to the baseline in the evaluated setting.
