RESEARCH & PROJECT · 01

AutoFiC : 취약점 탐지부터 PR 생성까지 자동화된 보안 패치 파이프라인

프로젝트 소개
  • SAST 탐지 → LLM 기반 패치 생성 → PR 생성 End-to-End 자동화 파이프라인 개발
  • XML 구조화 컨텍스트와 Annotation으로 취약 구간을 명시하고 수정 범위를 한정
주요 기술

Python · Semgrep · CodeQL · Snyk Code · OpenAI API · GitHub Actions

담당 역할
  • Project Manager : 일정 관리 및 업무 분담
  • SAST 실행 자동화 및 결과 통합 : Semgrep, CodeQL, Snyk Code 실행과 분석 결과 전처리
성과
  • 파이프라인 실행 성공 86/91개 프로젝트(94.5%), 정적 분석 경고 397/441건 제거(90.0%)
  • 생성한 Pull Request 중 7건 실제 저장소 병합

RESEARCH & PROJECT · 02

자동 패치 정확성 검증을 위한 LLM Oracle 설계

연구 소개
  • 정적 분석 경고 제거만으로 패치의 정확성을 보장할 수 없다는 한계에서 출발
  • 기존 LLM 기반 패치 검증 도구에서 생성된 테스트의 오류를 분석하고 검증 성능 개선
주요 기술

Python · Java · OpenAI API · Llama 3.2

담당 역할
  • LLM 생성 테스트의 의미적 불충분성과 구문적 유효성 문제 분석
  • 오류 유형에 따른 6가지 프롬프트 전략 설계 및 모델별 효과 비교
성과
  • Defects4J의 잘못된 패치 109개와 3가지 LLM을 대상으로 실험
  • 잘못된 패치 탐지 성능 GPT-4o-mini 최대 7.5%p, Llama 3.2 3B 최대 19.9%p 향상
