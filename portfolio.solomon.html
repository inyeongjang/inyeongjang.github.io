RESEARCH & PROJECT · 01

AutoFiC : 취약점 탐지부터 PR 생성까지 자동화된 보안 패치 파이프라인

프로젝트 소개
  • 정적 분석 도구(SAST)의 취약점 탐지 결과를 LLM으로 분석해
    자동 패치부터 Pull Request 생성까지 연계하는 End-to-End 파이프라인 구현
  • XML 기반 구조화 컨텍스트와 Annotation 기반 위치 강조로
    취약 구간을 명확히 전달하고 수정 범위를 한정
담당 역할
  • Project Manager : 일정 관리 및 업무 분담
  • SAST 자동화 설계 : 정적 분석 결과를 LLM 입력에 적합한 형태로 구조화하는 로직 구현
성과
  • 파이프라인 성공률 94.5%, 취약점 해결률 90.0% 기록
  • AutoFiC이 생성한 Pull Request 중 7건이 실제 저장소에 병합
🏆 KCSE 2026 우수 학부생 논문상 수상

RESEARCH & PROJECT · 02

자동 패치 정확성 검증을 위한 LLM Oracle 설계

연구 소개
  • 부정확한 패치를 자동으로 식별하기 위한 다양한 LLM 프롬프트 전략 비교·분석
담당 역할
  • 전체 실험 구조 및 프롬프트 전략 설계
  • 평가 지표 정의 및 실험 결과 분석
성과
  • Defects4J의 부정확한 패치 109개와 서로 다른 규모의 LLM을 대상으로 6가지 전략 평가
  • 역할 정의로 목표를 명시해 GPT 계열 모델의 식별 성능을 최대 7.5% 향상
  • 엄격한 출력 형식과 예시를 적용해 Llama 계열 모델의 식별 성능을 최대 19.9% 향상
