RESEARCH & PROJECT · 01

AutoFiC : 취약점 탐지부터 PR 생성까지 자동화된 보안 패치 파이프라인 ↗

프로젝트 소개
  • 정적 분석 도구(SAST)의 취약점 탐지 결과를 LLM으로 분석해
    자동 패치부터 Pull Request 생성까지 연계하는 End-to-End 파이프라인을 구현했습니다.
  • XML 기반 구조화 컨텍스트와 Annotation 기반 위치 강조로
    취약 구간을 명확히 전달하고 수정 범위를 한정했습니다.
담당 역할
  • Project Manager : 일정 관리 및 업무 분담
  • SAST 자동화 설계 및 전처리 : 정적 분석 결과를 LLM 입력에 적합한 형태로 구조화하는 로직 구현
성과
  • 91개 실제 GitHub 오픈소스 저장소를 대상으로 파이프라인을 평가했습니다.
  • 파이프라인 성공률 94.5%, 취약점 해결률 90.0%를 기록했습니다.
  • AutoFiC이 생성한 Pull Request 중 7건이 실제 저장소에 병합되었습니다.

RESEARCH & PROJECT · 02

자동 패치 정확성 검증을 위한 LLM Oracle 설계

연구 소개
  • 부정확한 패치를 자동으로 식별하기 위해 다양한 LLM 프롬프트 전략을 비교·분석한 연구입니다.
담당 역할
  • 전체 실험 구조 설계
  • Chain-of-Thought, Goal-Alignment 등 프롬프트 전략 설계
  • 평가 지표 정의 및 실험 결과 분석
성과
  • Defects4J의 부정확한 패치 109개와 서로 다른 규모의 LLM을 대상으로 6가지 전략을 평가했습니다.
  • 역할 정의로 목표를 명시해 GPT 계열 모델의 식별 성능을 최대 7.5% 향상시켰습니다.
  • 엄격한 출력 형식과 예시를 적용해 Llama 계열 모델의 식별 성능을 최대 19.9% 향상시켰습니다.
